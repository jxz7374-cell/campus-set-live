# 校园集合实验室 · 数据结构课程设计

基于**顺序表（一维数组）**的集合运算，包含两部分：

1. **`src/set_collection.c`**：课程设计本体，可编译运行的 C 控制台程序（交作业用）。
2. **`index.html`**：粉紫改为青墨高级风的在线交互展示页（部署到公网/现场演示用），与 C 版同一套算法。

---

├── src/

## 二、C 程序怎么编译运行（对齐实验 8 项，兼容老 Dev-C++）

- **老 Dev-C++ 5.11（本课环境）**：打开 `src/set_collection.c`，按 **F11** 编译并运行；源码为 GBK 编码、C89 写法（变量在开头声明），不报 C99 错误，结束停在“请按任意键继续”。
- **Code::Blocks / VS Code / 新版 GCC**：直接打开编译运行；命令行 `gcc src/set_collection.c -o set_collection`。

**实验内容 8 项与程序的对应（函数名与指导书一致）：**

| 实验内容 | 程序函数 | 菜单入口 |
| --- | --- | --- |
| (1) 创建空集合 | `CreateSet()` | 启动即建立空集合 |
| (2) 从数组建立集合 | `CreateSetFromArray()` | 菜单 1 |
| (3) 查找元素 x | `Find()` | 菜单 2 |
| (4) 增加元素 x | `Add()`（自动去重） | 菜单 3 |
| (5) 删除元素 x | `Delete()` | 菜单 4 |
| (6) 求并集 | `Union()` | 菜单 1 / 菜单 6 |
| (7) 求交集 | `Intersection()` | 菜单 1 / 菜单 7 |
| (8) 输出集合 | `Print()` | 菜单 5 及各处 |

- 菜单 1 直接复现指导书示例（a c e h 与 f h b g d a），并集、交集结果与教材图 1.2 一致。
- 菜单 7 交集用于“共同好友”，菜单 8 为创新加分：可公选课程 = 全集 − 已修并集（并集 + 补集 `Complement()`）。
- 元素为指导书规定的 char 型，输入时用空格或逗号分隔，重复自动去重。

## 三、网页本地查看

直接双击 `index.html`，浏览器打开即可，无需联网、无需安装任何东西。

## 四、部署到公网（任选一种，都免费，不需要把密码给任何人）

### 方案 A：Netlify Drop（最简单，拖进去就有链接）
1. 打开 https://app.netlify.com/drop
2. 把整个 `campus-set-site` 文件夹拖进网页虚线框
3. 立刻得到一个 `https://xxx.netlify.app` 公网链接，可分享。

### 方案 B：GitHub Pages（你已有 GitHub 账号）
1. 把 `index.html` 和 `src/` 上传到你的仓库（可放一个子文件夹）。
2. 仓库 **Settings → Pages**，选择分支（如 main）和目录，保存。
3. 稍等 1 分钟，得到 `https://用户名.github.io/仓库名/子目录/` 链接。

### 方案 C：Vercel
1. 打开 https://vercel.com ，用 GitHub 登录，导入仓库，直接 Deploy。

> 说明：GitHub Pages / Netlify / Vercel 都是**静态托管**，只能跑网页；C 程序是交作业/本地编译用，不能也不需要在网页服务器上运行。

## 五、网页功能
- **模块 01 共同好友 = 交集 A∩B**：点选两位同学，韦恩图高亮，列出共同好友。
- **模块 02 双条件同好 = 多集合交集**：选两个兴趣，筛出同时具备的人。
- **模块 03 可公选课程 = 补集 U−(A∪B)**：先并集去重两人已修课，再从全集减去。
- **模块 04 全体同学档案**：集中查看每位同学的好友、已选课程与兴趣爱好，新增同学自动并入。
- 左栏「添加新同学」可自行录入姓名、好友、课程、兴趣，即时进入名单。

## 六、算法与复杂度
| 场景 | 集合运算 | 时间复杂度 |
|---|---|---|
| 共同好友 | A ∩ B | O(\|A\|·\|B\|) |
| 双条件同好 | 标签 ∩ 条件1 ∩ 条件2 | O(n·k) |
| 可公选课程 | U − (A ∪ B) | O(\|U\|+\|A\|+\|B\|) |

底层均为手写顺序表 + 线性查找，未调用任何内置集合库。
